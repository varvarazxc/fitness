 Шаг 1. Подготовка базы данных
1. Установите и запустите сервер MySQL (например, через XAMPP, OpenServer или MySQL Workbench).
2. Создайте новую пустую базу данных (например, назовите её `fitness_club`).
3. **Импортируйте дамп базы данных**: в корне проекта находится файл `Dump20261105.sql`. Импортируйте его в созданную базу данных через phpMyAdmin (вкладка «Импорт») или через консоль MySQL. 
   *В дампе уже содержатся все 4 таблицы (`clients`, `membership_types`, `memberships`, `visits`) и тестовые типы абонементов.*
Шаг 2. Настройка подключения к БД
1. Откройте файл `db.py` в любом текстовом редакторе.
2. Впишите **ваши личные данные** для подключения к MySQL:
   ```python
   def get_db():
       return mysql.connector.connect(
           host="localhost",
           user="root",              # Ваш логин в MySQL (обычно root)
           password="",              # ВАШ ПАРОЛЬ от MySQL (впишите свой!)
           database="fitness_club"   # Название базы данных, которую вы создали
       )
Шаг 3. Установка зависимостей и запуск
Откройте терминал (командную строку) в папке с проектом.

Установите необходимые библиотеки:

bash
pip install flask mysql-connector-python
Запустите приложение:

bash
python app.py
